## Conceitos

- **Planejamento do Projeto:** Consiste em definir como o trabalho será organizado, executado e acompanhado para alcançar os objetivos estabelecidos. Permite reduzir incertezas antes da execução e, com menos incertezas, alocar recursos escassos com mais precisão e objetividade.
- **Por que planejar:** O planejamento define o quê, como, quando e com quais recursos o trabalho será realizado. A execução coloca o planejamento em prática, realizando as atividades e entregas previstas (Planejamento → Execução).
- **Marcos (milestones):** Eventos ou pontos importantes do projeto. Representam pontos de controle, geralmente possuem duração zero no cronograma, não representam necessariamente uma atividade e indicam a conclusão de uma entrega importante.
- **Dependências entre atividades:** Definem a relação entre as atividades e determinam a ordem em que devem ser realizadas.

## Principais objetivos do planejamento

- Organizar o trabalho necessário para realizar as entregas
- Definir as atividades e suas dependências
- Estimar recursos e durações
- Estabelecer o cronograma do projeto
- Criar uma referência para acompanhar o progresso e controlar mudanças

## Etapas do planejamento

- Definir o que precisa ser realizado
- Antecipar recursos e prazos
- Identificar dependências e possíveis problemas
- Facilitar o acompanhamento do projeto
- Orientar a tomada de decisões

## Gerenciamento do Tempo do Projeto

- **Planejar o gerenciamento do cronograma:** Estabelecer as políticas, os procedimentos e a documentação para planejar, desenvolver, gerenciar, executar e controlar o cronograma do projeto.
- **Definir as atividades:** Identificar e documentar as ações específicas a serem realizadas para produzir as entregas do projeto.
- **Sequenciar as atividades:** Identificar e documentar os relacionamentos entre as atividades do projeto.
- **Estimar os recursos das atividades:** Estimar os tipos e quantidades de material, recursos humanos, equipamentos ou suprimentos necessários para realizar cada atividade.
- **Estimar as durações das atividades:** Estimar o número de períodos de trabalho necessários para terminar atividades específicas com os recursos estimados.
- **Desenvolver o cronograma:** Analisar as sequências das atividades, suas durações, recursos necessários e restrições, visando criar o modelo do cronograma do projeto.
- **Controlar o cronograma:** Monitorar o andamento das atividades para atualizar o progresso e gerenciar as mudanças feitas na linha de base do cronograma.

## Tipos de dependência entre atividades

- **Término → Início:** uma atividade termina para outra começar.
- **Início → Início:** duas atividades podem começar juntas.
- **Término → Término:** duas atividades devem terminar juntas.
- **Início → Término:** uma atividade precisa começar para outra terminar.

Exemplo de sequência: Levantar requisitos → Desenvolver sistema → Realizar testes → Homologar → Implantar.

## Estimativa de atividades

- No gerenciamento **tradicional**, a duração é estimada considerando recursos disponíveis, complexidade e experiência com atividades semelhantes. Uma entrega deve ser decomposta em componentes menores até atingir um nível de granularidade adequado para planejar, estimar e controlar o trabalho.
- Em **métodos ágeis**, a equipe pode estimar o esforço relativo em vez de definir diretamente uma duração. Exemplos: Planning Poker, Story Points, T-Shirt Sizes.
